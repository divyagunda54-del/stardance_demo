Introduction

Want to keep track of how many hours you spend building cool projects in Hack Club? Hackatime sits right in your code editor, silently keeping track of files, active coding time, and languages you use. It is a completely free, open-source, privacy-focused alternative to WakaTime.

What You Need First
  • A code editor (like VS Code, PyCharm, Vim, Xcode, etc.)
  • A registered Hackatime account
  • About 3 minutes of your time!

Step 1: Run Automated Setup

Before installing your editor's plugin, run our automated setup tutorial. It automatically provisions your API key and configures the local Hackatime endpoint on your operating system so the plugin works perfectly right out of the box!

Security Alert

Your Hackatime API key behaves just like a password. Never share it, publish it in public repositories, or paste it in general Slack channels.

VS Code Setup Guide

Extension Marketplace
  1. Launch **VS Code**.
  2. Open the Extensions panel (`Ctrl+Shift+X` or `Cmd+Shift+X`).
  3. Search for **WakaTime** and click **Install**.
  4. When prompted, click **Enter API Key** (or open Command Palette with `Cmd+Shift+P` / `Ctrl+Shift+P` and type `> WakaTime: API Key`).
  5. Paste in your generated API key (it was auto-copied when you ran Step 1!).

Need Help?

Not seeing your time show up in your statistics or running into issues during the configuration? Don't stress, here are the answers to the most common configuration errors.

This is almost always caused by an incorrect WakaTime configuration pointing to the wrong endpoint. Open up your configurations:

  • Mac/Linux: Edit `~/.wakatime.cfg`
  • Windows: Edit `%USERPROFILE%\.wakatime.cfg`

Make sure the **api_url** is written exactly like this:

api_url = https://hackatime.hackclub.com/api/hackatime/v1

First, check that you have the latest version of your editor plugin installed. If it continues to bug out, try closing and opening your editor again. This forces the editor's WakaTime integration service to rebuild its local API parameters.

Don't worry! Hop directly into the **Hack Club Slack** workspace and ask in the dedicated #hackatime-help channel. Our community is happy to help you debug your configuration.
